# Aplikasi Kasir dan Stok Sederhana

## Deskripsi
Aplikasi Kasir dan Stok Sederhana merupakan proyek kelompok mata kuliah Pemrograman Berbasis Web (PBW). Aplikasi ini dibuat untuk membantu proses pengelolaan produk dan stok barang secara sederhana.

## Latar Belakang
Usaha kecil seperti warung makan, kedai minuman, dan toko sederhana membutuhkan pengelolaan produk, stok, dan transaksi penjualan yang mudah. Pencatatan secara manual terkadang menyulitkan pemilik usaha dalam memantau stok dan menghitung hasil penjualan. Oleh karena itu, dibuat aplikasi Cashere sebagai sistem kasir sederhana berbasis web untuk membantu pengelolaan produk, stok, dan transaksi penjualan agar lebih mudah dan terorganisir.

## Tujuan
- Mempermudah pengelolaan data produk.
- Membantu pencatatan dan pemantauan stok barang.
- Mempermudah proses transaksi penjualan.
- Membantu pemilik usaha melihat laporan penjualan.
- Menyediakan aplikasi kasir berbasis web yang sederhana dan mudah digunakan.

## Target Pengguna
- Admin atau pemilik usaha yang mengelola produk, stok, dan laporan penjualan.
- Kasir atau karyawan yang bertugas melayani pembeli dan mencatat transaksi penjualan.

## Fitur
- Login dan logout pengguna.
- Dashboard admin.
- Pengelolaan data produk.
- Pengelolaan kategori produk.
- Pengelolaan stok barang.
- Transaksi penjualan.
- Pengurangan stok otomatis setelah transaksi.
- Pencarian dan penyaringan produk.
- Laporan penjualan.
- Tampilan tanggal dan waktu.
- Validasi input formulir.

## Teknologi
- HTML5 untuk struktur halaman web.
- CSS3 untuk desain dan tampilan responsif.
- JavaScript untuk interaksi dan validasi formulir.
- PHP untuk proses backend dan autentikasi.
- MySQL untuk penyimpanan database.
- jQuery dan AJAX untuk interaksi data.
- Git dan GitHub untuk pengelolaan versi kode.
