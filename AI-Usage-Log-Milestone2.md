# AI Usage Log - Milestone 2

## Proyek Aplikasi Kasir dan Stok Sederhana

### 1. Penggunaan AI
- Tanggal: 5–6 November 2026
- AI yang digunakan: ChatGPT.
- Tujuan: Membantu pengembangan tampilan awal aplikasi kasir dan pengelolaan repository GitHub.

### 2. Bantuan yang Diberikan
- Memeriksa struktur HTML dan JavaScript.
- Membantu menambahkan CSS responsif untuk tampilan mobile.
- Membantu merapikan posisi informasi tanggal, waktu, identitas admin, dan tombol logout pada navbar.
- Membantu memeriksa validasi form produk.
- Membantu penggunaan Git untuk menyimpan dan mengunggah perubahan ke GitHub.

### 3. Penjelasan Kode oleh Mahasiswa
- HTML digunakan untuk menyusun struktur halaman login dan dashboard.
- CSS digunakan untuk mengatur warna, tata letak, dan tampilan responsif.
- JavaScript digunakan untuk menampilkan tanggal dan waktu serta menangani interaksi form.
- Git digunakan untuk menyimpan riwayat perubahan kode.

### 4. Perubahan yang Dilakukan
- Menambahkan CSS responsif pada dashboard.
- Merapikan susunan navbar pada layar mobile.
- Mengatur posisi tanggal dan waktu agar tidak bertumpuk dengan informasi admin dan tombol logout.
- Mempertahankan struktur dan kode awal kelompok.

### 5. Hasil Pengujian
- Login simulasi berhasil membuka dashboard.
- Validasi form menampilkan peringatan ketika kolom wajib belum diisi.
- Form produk menampilkan pesan simulasi ketika berhasil dikirim.
- Tampilan dashboard telah diuji pada desktop dan perangkat mobile.
- Perubahan berhasil disimpan dan diunggah ke GitHub.

### 6. Evaluasi
Penggunaan AI membantu proses pengembangan dan pemahaman kode. Setiap perubahan diperiksa dan diuji sebelum digunakan. Mahasiswa tetap mempelajari fungsi kode agar dapat menjelaskannya saat presentasi.
